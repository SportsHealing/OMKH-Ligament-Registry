Your record, locked on your device

The plan is for each record to sit in its own encrypted vault, based on the sgit design. Data is encrypted on the device with AES-256-GCM before it is uploaded. The server never sees the contents, file names or keys.

Key recovery for a clinical system is still an open question. This mock-up has no real encryption.
