Proposed redraft of the UK National Ligament Registry

A clear record of every knee ligament repair.

Surgeons, patients and clinic teams add to one record. Patients score their knee before surgery and for ten years after. The registry tracks which repairs last.

Follow-up

Scores at set points after surgery

Patients fill in four short scores: IKDC, KOOS, a short form pain score and SANE. The main result the registry tracks is whether a knee needs revision surgery.

Security

Records locked on the device

The plan is for each record to sit in its own encrypted vault, based on the sgit design, which is in beta. Data would be encrypted on the device before upload, so the server never sees the contents, file names or keys.

This mock-up has no real login, no encryption and no storage. How a lost vault key is recovered is still an open question. Read the security page.
